# 한국골드마켓 고객 안내 문구 원칙

## 문장과 용어

- 고객이 할 일과 얻는 결과를 먼저 말합니다. 제목은 짧게, 설명은 한두 문장으로 씁니다.
- 설명과 도움말은 ‘해요 / 해주세요 / 해보세요’로 자연스럽게 안내합니다. 버튼은 ‘기록하기 / 받기 / 예약 요청’처럼 짧게 씁니다.
- 성공·실패·대기 상태를 정확히 구분합니다. 아직 저장되지 않았거나 혜택 지급을 확인하지 못한 상태에서 완료를 단정하지 않습니다.
- 같은 화면에서 같은 설명을 반복하지 않습니다. 입력 안내는 입력 옆, 비용은 선택 결과 옆, 예약 확정 여부는 요청 버튼과 완료 상태에 배치합니다.
- 일반 화면에서는 ‘푸시 / FCM / 토큰 / 서버’ 대신 ‘알림 / 소식 / 기기 연결 / 확인’을 씁니다. 전문 정보는 고객지원용 도움말에 남깁니다.
- 값은 ‘예상 가치’, 실제 보유 금은 ‘내 금 기록’, 회원혜택은 ‘MEMBER GOLD’로 구분합니다.
- 기술적인 문장을 감성적인 표현으로 바꾸면서 의미를 흐리지 않습니다. 실제로 하지 않는 일을 약속하지 않습니다.

## 동의와 중요 안내

- ‘금시세·혜택 소식’ 옆에는 ‘광고성 정보 수신 동의 (선택)’를 명확히 표시합니다. 동의와 기기 알림 권한은 서로 다릅니다.
- MY GOLD 목표 알림은 광고성 소식 동의와 별도임을 유지합니다. 설정만 보고 실제 알림 수신을 보장하지 않습니다.
- 혜택은 ‘조건 충족 시’ 제공됩니다. 금액·사용 조건·지급 이력·차감 시점을 부드러운 표현을 이유로 생략하지 않습니다.
- 금 기록이 실물 보관·예치가 아니라는 점과 기기 내 임시 저장 범위를 유지합니다. 필요한 상세 설명은 펼침 안내로 정리할 수 있습니다.
- 부족분 비용·추가 공임·현장 순도 및 중량 확인·고객 동의, 예약 요청과 확정의 차이는 고객이 결정하는 위치에 둡니다.
- 약관·개인정보처리방침·계정 영구 삭제·금전 및 중량 조건은 일반 안내와 구분해 의미를 보존합니다.

## 확인 방법

문구만 바꿔도 긴 버튼이 좁은 앱 화면에서 줄바꿈될 수 있습니다. 실제 웹과 390px 모바일 화면을 확인합니다. 선택 동의 기본값과 이벤트 처리, 저장·알림·계산 로직도 함께 확인하되 화면용 문구를 업무 규칙으로 사용하지 않습니다.
