# 한국골드마켓 금교환 구조 법률·세무 검토 요청서

이 문서는 변호사·세무사에게 사실관계와 질문을 빠짐없이 전달하기 위한
검토 자료이며, 법률 또는 세무 자문 그 자체가 아니다. 전문가 답변을 받은
뒤 이용약관·개인정보처리방침·영수증 및 회계 처리를 최종 확정한다.

## 1. 서비스 개요

- 운영자: 원일귀금속
- 서비스: 고객이 보유한 귀금속의 예상 순금 중량을 확인하고 방문 예약 후
  매장에서 감정·계량하여 골드바로 교환
- 신청 채널: koreagoldmarket.com
- 이행 장소: 부산 부산진구 범천동 원일귀금속
- 회원 혜택: 웰컴·퀵퀴즈 순금 보너스, 골드바 교환 시 사용
- 주요 기록: 예약 신청, 상태 변경, 최종 인정 순금량, 보너스 사용,
  골드바 구성, 담당 관리자, 감사 로그

## 2. 실제 거래 흐름

1. 고객이 온라인에서 보유 품목과 예상 중량을 입력한다.
2. 시스템은 예상 순금량을 표시하며 방문 예약을 접수한다.
3. 관리자가 예약을 승인하고 고객에게 알림을 보낸다.
4. 고객이 매장을 방문한다.
5. 매장에서 실물 상태, 함량, 계량 결과와 공임을 확인한다.
6. 고객 동의 후 최종 인정 순금량과 지급 골드바 구성을 확정한다.
7. 보너스 순금 사용 요청은 고객 요청과 관리자 확인을 모두 기록한다.
8. 완료 처리 후 관리자 감사 로그를 남긴다. 고객용 완료확인서는 자동 생성하지 않는다.

## 3. 법률 검토 질문

- 이 구조가 민법상 교환, 매매, 가공·용역 또는 혼합계약 중 무엇에 해당하는가?
- 온라인 예약 시점과 매장 최종 확인 시점 중 계약 체결 시점은 언제인가?
- 예상값과 현장 감정값의 차이, 중량 오차, 함량 판정 기준을 어떤 문구로
  고지해야 하는가?
- 실물 인도 이후 소유권 이전 시점과 보관·분실·훼손 책임은 어떻게 정해야 하는가?
- 고객이 현장 결과에 동의하지 않을 때 철회와 실물 반환 절차는 어떻게 정해야 하는가?
- 전자상거래법상 통신판매, 청약철회, 사업자 표시 의무가 적용되는가?
- 귀금속 매입·교환과 관련한 본인확인, 장물 방지, 자금세탁 방지 의무가 있는가?
- 미성년자 이용 제한과 법정대리인 동의가 필요한가?
- 자동 완료확인서를 생성하지 않는 현재 구조에서 법적으로 별도 현장 증빙이나 고객 서명이 필요한가?
- 후기 공개 시 거래 사실 검증, 비식별화, 삭제 요청 기준은 적절한가?

## 4. 세무·회계 검토 질문

- 고객 귀금속 수취와 골드바 지급을 각각 어떤 거래로 장부 처리해야 하는가?
- 부가가치세 과세표준은 골드바 전체가액, 차액, 공임 중 무엇인가?
- 고객에게 발급할 세금계산서, 현금영수증, 매입증빙 또는 교환확인서는 무엇인가?
- 고객 실물의 매입가와 재고 취득가액은 어떤 시세와 시점으로 평가해야 하는가?
- 공임, 분석료, 손실률, 부가세를 화면과 회계 증빙에 어떻게 구분 표시해야 하는가?
- 웰컴·퀵퀴즈 보너스 순금은 충당부채, 판매촉진비, 할인 중 어떻게 처리하는가?
- 보너스의 소멸시효·환불 불가·현금 전환 불가 조건은 회계상 적절한가?
- 시세 변동으로 발생하는 손익과 재고평가 방식을 어떻게 문서화해야 하는가?
- 거래별로 보존해야 하는 계량표, 사진, 동의 기록과 보존 기간은 얼마인가?

## 5. 개인정보 검토 질문

- 예약에 주소와 이메일을 받지 않고 이름, 휴대전화, 방문일정만 처리하는 것이
  최소수집 원칙에 부합하는가?
- Firebase Authentication, Firestore, Cloud Functions, FCM 사용에 따른
  국외 이전 또는 처리위탁 고지가 필요한가?
- 거래 기록, 알림 토큰, 고객 문의, 감사 로그의 각각의 보존 기간은 얼마가 적절한가?
- 회원 탈퇴 시 거래 증빙은 어떤 근거로 보존하고 어떤 필드를 비식별화해야 하는가?
- SMS MFA와 푸시 알림에 필요한 전화번호·토큰의 동의 및 철회 절차는 적절한가?

## 6. 전문가에게 전달할 첨부자료

- 최신 이용약관과 개인정보처리방침
- 금교환 신청 화면 캡처
- 관리자 승인·완료 화면 캡처
- 고객 안내 문구 샘플
- 보너스 적립·사용 원장 샘플
- Firestore 주요 문서 스키마(개인정보 값은 제거)
- 수수료·공임표와 실제 회계 분개 예시
